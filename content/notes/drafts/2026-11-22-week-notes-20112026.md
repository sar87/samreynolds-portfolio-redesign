This week began with working on preparing datasets for Synthesaurus, and ended with a trip to Heidelberg. 

### Synthesaurus - preparing the data

I have been breaking down a large snapshot of XML papers that have been provided by Taposaur, our agentic paper downloader. The aim of which is to be able to recreate the conditions use to create the butterfly and moth synopsis as manually curated by the Conservation Evidence team. The full snapshot contained somewhere in the region of 600,000 XMLs, narrowing those down to ones containing all the metadata needed for Synthesaurus (namely title, abstract and full text) narrowed the dataset down to approximately 300,000 files. 

I have then matched these up to, firstly the accepted set of papers in the synopsis and then also the papers that were reviewed by the team but rejected. This leaves a set of ~150,000 XML files that can be used to test the pipeline. The hope is that this week I can run a few smoke tests and get this evaluation underway. The reason I couldn't do it this week was because of my trip to Germany.
